# UNAGSA – University of Nairobi Anthropology and Gender Students Association

A web platform developed for the University of Nairobi Anthropology and Gender Students Association (UNAGSA), dedicated to representing the academic, social, and developmental needs of students in the fields of Anthropology and Gender Studies.

## 🌍 About UNAGSA

UNAGSA is a dynamic student organization committed to:

- Advocating for greater appreciation of anthropology through the exploration of human diversity and gender.
- Fostering a collaborative environment between students, academic staff, and industry professionals.
- Promoting awareness and appreciation for the disciplines of Anthropology and Gender Studies.

**Motto:** *Exploration of Human Diversity*

## 🌐 Live Website

Access the live platform here: [https://unagsa.netlify.app/](https://unagsa.netlify.app/)

## 🚀 Features

- Informational sections about UNAGSA's mission, goals, and activities.
- Event listings and magazine publications.
- Membership sign-up functionality.
- Responsive design for accessibility on various devices.

- [React](https://reactjs.org/) – JavaScript library for building user interfaces.

- [ESLint](https://eslint.org/) – Pluggable JavaScript linter.

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nzyokam/uon-unagsa.git
   cd uon-unagsa
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

## 💻 Development

Start the development server:

```bash
npm run dev
# or
yarn dev
```

The application will be available at `http://localhost:5173/` by default.

## 🏗️ Build

Generate a production build:

```bash
npm run build
# or
yarn build
```

The optimized and minified output will be in the `dist` directory.
